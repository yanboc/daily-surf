## Topics（主题）

1. **LLM 后训练 / 微调 / 对齐（Post-training, Fine-tuning, Alignment）**：偏好 SFT、RLHF/DPO/reward modeling、对齐流程，而不是单纯 pretraining 或架构。
2. **Agentic AI（智能体）**：多 agent 协作、工具调用、规划、任务分解；关注能让 agent 真正完成长程任务的机制。
3. **Agent Memory（智能体记忆）**：长期/短期记忆、经验回放、RAG 之上的记忆管理；关注记忆如何跨越会话持续生效。
4. **Context Management（上下文管理）**：长上下文压缩、上下文窗口利用、KV cache、注意力外的上下文工程；与 Agent Memory 有交集，区别在「单次调用内的上下文利用」vs「跨调用/跨会话的状态保持」。

> 说明：Topic 2/3/4 与 Topic 1 的部分重叠是刻意保留的——前三个是从「LLM 能力」延伸出来的 agent 视角，第 4 个偏系统/工程。若后续感觉重复可合并。
