# 论文 taste

> 记录我对论文的主题、作者、出版物偏好。每次产出内容后，根据反馈更新本文件。

## Topics（主题）

1. **办公 / 企业知识工作中的 Agent**：文档、表格、邮件、会议、日程与跨应用流程；重点看权限、审计、可靠性、人机审批、系统集成和真实 ROI，而非演示型自动化。
2. **Agent Memory（最高优先级）**：长期/短期记忆、经验回放、记忆写入/检索/遗忘、跨会话状态，以及记忆可迁移性和评价方法。
3. **Context Management / Context Engineering（最高优先级）**：上下文选择、压缩、隔离、分层、长上下文利用和上下文管理器；区分单次调用内上下文与跨调用记忆。
4. **Multi-Agent 协同（最高优先级）**：通信协议、任务分解、共享记忆、冲突处理、信用分配、协作涌现和规模化成本。

> 说明：Topic 2/3/4 与 Topic 1 的部分重叠是刻意保留的——前三个是从「LLM 能力」延伸出来的 agent 视角，第 4 个偏系统/工程。若后续感觉重复可合并。

## 风格偏好

- 必须阅读方法、实验/案例与 limitations，不能只转述摘要。
- 优先有消融、真实任务、可复现代码和失败分析的工作。
