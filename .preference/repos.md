# 代码仓偏好（repos）

> 记录我对开源代码仓的喜好：哪些库值得关注、为什么。每次产出后根据反馈更新。

## 关注方向

- **办公 Agent**：文档、表格、邮件、会议、日程、知识库和跨应用工作流。
- **Agent harness**：记忆、上下文管理、工具协议、可观测性、权限、安全、人机审批和评测。
- **多 Agent 基础设施**：通信、共享状态、任务协调、冲突处理和成本控制。

## 证据要求

- 必须阅读 README、官方文档，并检查关键设计/代码或近期 release/commit。

## 排除项

- 纯营销、文档空泛、无法定位关键实现、与办公/Agent 基础设施弱相关的仓库。
