1. **[MemCodex: Self-Programming Hierarchical Memory for Language Agents](https://arxiv.org/abs/2609.39765)**
   - 元信息：2026-09-30（arxiv abs；v1 submitted 2026-09-30；cs.CL）；预印本；主题标签：Agent Memory / 分层可执行记忆程序 / 按方法进化 / MemArena·路由回源 / LoCoMo·LongMemEval·MAB·PersonaMind；分级：S
   - 核心问题：Agent 记忆的访问需求异质——单跳要原文、多跳要跨会话链、时序要带日期事件、重复流程要技能——手写流水线把「有哪些组织」和「如何选用」都写死；既有自适应方法只在预定义模块空间上搜索或学策略，设计空间本身仍封闭。
   - 机制/设计：MemCodex 把记忆建成粗到细的可执行层程序：`skill / graph / summary / raw`（另加写侧 Metis-27B 的 kv 潜记忆，不进化）。每层固定五方法：`admit`/`index`/`propose`（写）与 `score`/`route`（读，Stop/Narrow/Descend）。派生项保留精确源回合 `src(x)`；默认走路由通道——读到摘要/断言后回落到源回合再组装上下文，而非只塞派生文本。程序进化：元 Agent 每次只改一层的一个方法或开关一层；有效性检查 \(\mathcal{K}\) 后，接受测试要求 \(\Delta_{\mathrm{tok}}\leq 0\) 且 \(\Delta_{\mathrm{acc}}\geq 0\)，准确率上升须一侧 McNemar \(p<\alpha=0.05\)；接受架构进档案树。评测套件 MemArena：LoCoMo / LongMemEval(S) / MemoryAgentBench / PersonaMind（自建 1500 题）；evolve 用每基准 20% 分层题，任务 Agent 与裁判冻结；骨干 Qwen3.5-27B（NL+KV）与 GPT-5.4-mini（仅 NL），裁判 GPT-4o-mini；\(T=8,P=4,H=2\)。
   - 证据：Qwen3.5-27B 上四基准均值 Acc 60.8，相对最强自适应基线 MemPro +5.6，tok/q 2.0k vs 6.8k（约 \(3.4\times\) 少），延迟约 \(2.1\times\) 快；相对全文 21.4k tokens +7.2。初架构 \(g_0\) 已 56.8（证据回源），进化再 +4.0 且 tok −17%。消融：仅 raw 54.1；内容通道 55.4（Rec 63.0）vs 路由 60.8（Rec 88.4）；无进化/模块选择/整层改写/整程序改写分别 56.8/58.3/57.2/56.7。记录不相交划分下仍领先 MemPro +5.0；原生 \(g^\star\) 比跨基准迁移架构高 1.5–2.8 点。
   - 局限：正文无独立 Limitations；结论与 RQ6——进化架构强任务特异，迁移只保留约三分之一增益；API 骨干无权重则无 kv 潜记忆；进化需 evolve 切分与多轮子代评估成本。评测主域为长对话/个性化回忆，非邮件日历写副作用。失败条件：把派生摘要当最终证据（内容通道 Rec 崩）；或关掉接受测试让噪声子代入库（测试保留率从 53–78% 掉到 10–24%）。
   - 对办公 Agent 或 Agent 基础设施的意义：给「客户事实 / 项目 SOP / 跨会话偏好」记忆一层可验收合同——分层写读程序可自改，但每条派生记忆必须可溯源到原始回合，读默认回落到源证据。生产可把「route 不得被过期摘要 Stop」「写入前回放校验技能」「acc↑ 且 tok 不增」做成记忆回归门，并按任务族分别进化而非假设一份全局记忆程序通吃。

2. **[Persistent Context Graphs for Efficient Memory Compaction in LLM Agents](https://arxiv.org/abs/2609.40118)**
   - 元信息：2026-09-30（arxiv abs；v1 submitted 2026-09-30；cs.CL；UCSB + Microsoft 等；代码 UCSB-NLP-Chang/ReCAP）；预印本；主题标签：Context Engineering / 记忆压缩 / 持久上下文图·注意力依赖 / 无额外模型调用 / SWE-Together·Lost-in-Conversation；分级：S
   - 核心问题：长程 Agent 历史撑爆窗口且反复 prefill 昂贵；摘要/再编码压缩要额外模型算力且不可逆丢细节，KV 淘汰在新请求改向后失效，冷启动（用户思考占会话约 92%）又迫使重编码。需要：新请求到达时从全量档案选上下文、不额外调模型、且与 KV 过期解耦。
   - 机制/设计：ReCAP 在每轮执行后，用本已算过的注意力维护持久图：节点=用户消息或「工具调用+结果」块，分数 \(u_t\) 为注意力 EMA；边=支持→依赖（注意力质量超阈）；另标观测集与可能被覆盖的 stale。新请求到达：IDF 标识符重叠 \(\ell_v\) + 标准化 \(u_t\) 打分，先保留保护集 \(P_t\)（全部用户指令 + 每文件最新写/编辑），再按预算 \(\beta=0.1\) 打包，再一跳扩依赖（至多 \((1+\delta)B\)）。选择固定于本轮工具步以利前缀缓存；图更新可后台跑。闭源 Agent 可用 Qwen3-0.6B 代理注意力映射回同块。评测：SWE-Together 106 任务、Lost-in-Conversation 代码子集 100 例×5 对话；骨干 Qwen3-Coder-30B-A3B 与 gpt-oss-20b。
   - 证据：相对 Codex 式摘要，压缩+冷恢复估计延迟约 −95%（Qwen/gpt-oss）。SWE-Together：相对全文历史约减半上下文，Qwen 奖励 28.5 vs Full 24.4（Ctx 15.3k vs 28.5k）；与 Summarize 28.7 接近但无 +71k/+397 摘要 token。LiC：Acc 85.4 / 67.6 vs Full 65.6 / 26.4（+19.8 / +41.2），Ctx 94 / 73 vs Summarize 372 / 602。去掉注意力图 LiC −8.8；70% 轮次可复活曾省略块。0.6B 代理注意力与自注意力无显著差。
   - 局限：正文无独立 Limitations；主域为编码 Agent（SWE/多轮代码对话），非邮件日历写闸；标识符启发式偏代码符号；依赖可采样注意力或小模型代理。Appendix A 失败 vignette：无保护集时冷启动可丢掉任务陈述或刚写完的编辑记录，Agent 发明假问题或误判「已修好」。失败条件：只按分数打包却不保护用户指令/最新写记录；或把 Peak 降幅当成功却未盯任务骨架是否仍在上下文。
   - 对办公 Agent 或 Agent 基础设施的意义：把 compaction 从「每轮再摘要」改成「持久注意力图 + 请求相关检索、零额外 LLM 调用」，并与前缀缓存互补（暖边界跳过选择）。办公长跑可类比：会话骨架（原始任务/审批约束/最近写回）必须硬保护，依赖边带回诊断证据；冷恢复延迟与「可复活省略块」应进 harness 回归，而不是只比压缩比。

3. **[Action Conditioned Bisimulation For GUI Agent Memory](https://arxiv.org/abs/2609.38778)**
   - 元信息：2026-09-30（arxiv abs；v1 submitted 2026-09-30；cs.AI）；预印本；主题标签：Agent Memory / GUI 状态抽象 / 动作条件双模拟 / APSG / MiniWoB++；分级：A
   - 核心问题：GUI/网页 Agent 的记忆首先要回答「这两页算不算同一状态」；按观察相似度合并会把同控件的不同标签页、菜单行等「看起来像、点了却不同」的页混在一起，召回自信但错误的动作。
   - 机制/设计：冻结策略在 GUI 上交互，累积经验转移图 \(P(s'|s,a)\) 与成功/失败/前进结果 \(\rho^\star\)。合并距离 \(d_a\) 比较共享动作下的结果差与后继块 TV；状态距离取共享动作上最坏情况，标签 \(\ell\)（目标槽位+角色多重集+可填槽）不同或共享动作为空则 \(d=\infty\)——观察相似度从不进入规则。对 \(B\) 做固定点迭代得 APSG 划分，整段替换既有 outcome-value 记忆的合并规则，下游价值/重排公式不变，以隔离准则效应。需 \(\epsilon\)-greedy 前三分之一回合探索（否则 \(|A(s)|=1\) 无法比较）；短名单控制付出相同二次调用与弯路但不记记忆。
   - 证据：MiniWoB++ 十个导航式任务，BrowserGym，冻结 Qwen3-8B，每任务 60 集（1–20 探索、21–60 贪心），评估半 400 配对格。APSG SR 0.782 vs ReAct 0.723（\(\Delta=+0.060\)，95% CI [0.033,0.090]，McNemar \(p<10^{-3}\)）；短名单控制/后继表示合并/观察合并相对 ReAct 无实质增益（观察合并甚至 −0.015）。增益集中在「容器」任务（标签页/菜单等）+0.075；非容器任务无不一致对。覆盖与覆盖率类似，但 APSG 覆盖精度多为失败→成功，观察合并多为反向。
   - 局限：正文无独立 Limitations；评测限于 MiniWoB++ 与单种子、八步帽；`click-menu-2` 反向未解释；依赖探索弯路成本；非真实企业桌面/Office 连接器。失败条件：用外观或后继占用合并「看起来像」的页；或缺共享动作证据仍合并（准则明确拒绝）。
   - 对办公 Agent 或 Agent 基础设施的意义：对浏览器/桌面/内部审批页 Agent，记忆键应从「截图像不像」改为「同一 affordance 下共享动作是否预测一致」。生产可把「标签页/下拉行/启用前后」类近外观状态的错误合并做成记忆回归负例，并要求写入前有共享动作证据，否则宁可不召回。
