1. **[STRATA: Self-Maintaining Structured Experience Graphs for Self-Evolving Language Agents](https://arxiv.org/abs/2610.19386)**
   - 元信息：2026-10-14（abs：Submitted on 14 Oct 2026；cs.AI；NJIT / CUHK Shenzhen；19 pages）；预印本；主题标签：Agent Memory / 三层经验图·typed reflector / contrast edges 负迁移 / AppWorld·WebArena·ALFWorld·ScienceWorld；分级：S
   - 核心问题：测试时自演化记忆多为单层池：轨迹、工作流与推理条同库、只靠 embedding 相似检索，既不遗忘也不去重；表面相似但方向相反的经验（heat vs cool）会被整段抄执行，使 Agent 比无记忆更差。能否用**类型化分层 + 自维护 + 反混淆边**同时控规模与负迁移？
   - 机制/设计：**STRATA** 三层有向图——atomic（技能/代码/子角色）、workflow（任务规程）、meta（任务族范式）；边含 call / generalizes / merged_from / contrasts。五机制共享同一相似几何：(1) 多维相似 \(s=W_c\cos e_c+W_i\cos e_i+W_t J(\mathrm{tags})+W_l\ell\)（\(W_c{=}0.40,W_t{=}0.30\)），op/obj 标签区分同物反操作；(2) typed reflector——仅成功 episode 结晶规程，失败最多挂 pitfall；按 tag 组经验贝叶斯自适应阈值决定 noop / add_bullet / create；(3) Louvain 社区诱导 meta（新颖度门 \(R_{\mathrm{meta}}{=}0.6\)）；(4) 压力触发 GC：质量 \(Q_i\) 删低分 workflow，Tarjan 保护 articulation point；(5) contrast 边按对立算子词表（如 heat↔cool）在检索时注入「do not confuse」。骨干冻结 DeepSeek-V4-Flash/Pro；在线单遍积累记忆；三 seed。
   - 证据：Pro 骨干四基准均值最强——AppWorld TN TGC **78.4**、TC TGC/SGC **57.2/46.5**、WebArena SR **45.6**、ALFWorld **98.6**、ScienceWorld **96.7**（A-Mem TN 77.2、TC 55.0/42.2；MemEvolve WebArena 41.0）。消融（Pro）：去 tag −13.1 / 去 contrast −6.5（SciW 96.7→**78.7**，ALF 98.6→**89.5**）/ 去自适应阈值 −5.9 / 去 meta −4.7 / 去 GC −2.2。成本：STRATA 延迟 **58.7s**、步数 **11.7**、记忆行 **23.3** vs A-Mem 41.9 行仍更高分。失败诊断：Hermes 在 SciW find-living 可到 **−80/−100**（无记忆可解）；WebArena 812 任务压成 112 workflow / 16 meta。
   - 局限：正文 Future Work——仅 DeepSeek-V4 一族，contrast 依赖骨干是否听从警告；对立算子靠手写词表；AppWorld TN↔TC、WebArena 对比纠缠难度/分布，非纯规模对照。失败条件：单层相似检索却宣称已控负迁移；或只链笔记从不抽象/遗忘却宣称可随任务集增长；或把「注入更多记忆行」当更好。

2. **[Cortex: Consolidating Context into Parametric Memory](https://arxiv.org/abs/2610.20399)**
   - 元信息：2026-10-14（abs：Submitted on 14 Oct 2026；cs.CL / cs.AI / cs.LG / cs.MA；Jintian Zhang / Ningyu Zhang 等；Technical report；将公开 testbed 与实现）；预印本；主题标签：Context Engineering·Parametric Memory / 记忆巩固 CR·RR / prospective rehearsal·FFN Synaptic/Structural / ALFWorld·τ²-Bench·编辑；分级：S
   - 核心问题：上下文能抬分，撤掉后增益常丢失——这是可测的 **memory failure**（context gap \(\Delta_{\mathrm{ctx}}>0\)）。如何把上下文诱导行为**内化为参数记忆**，同时保住非目标能力，并统一编辑、技能、人设与抑制？
   - 机制/设计：形式化 Memory Consolidation：\(\mathrm{CR}=(\mathrm{Perf}(M',Q_C^+)-\mathrm{Perf}(M,Q_C^+))/\Delta_{\mathrm{ctx}}\)，\(\mathrm{RR}=\mathrm{Perf}(M',Q_C^-)/\mathrm{Perf}(M,Q_C^-)\)；支持 single/batch/sequential。**Cortex**：(1) 预更新模型生成 prospective queries 与带上下文教师响应；(2) 只改 FFN——Synaptic 低秩增量或 Structural 新增非线性通道（MoE 用 shared expansion、router 冻结）；(3) 学生对齐教师输出 KL + FFN 残差后隐态 MSE；序列更新冻结旧参、只训新 \(\psi_t\)，replay 历史 query 但不存旧上下文。五任务族 testbed：agent 经验（ALFWorld / τ²-Bench）、新 API、人设、知识抑制、事实编辑。
   - 证据：多数设定至少一变体落在 CR–RR Pareto。Qwen2.5-14B 连续 50 次 zsRE：Structural **CR 88.9 / RR 99.8**（vs ROME CR 28.5；AlphaEdit 低约 66.2/3.8 pp）；每步仅约 0.74M 新参；终检重复/超长终止 **0.0%**（若干编辑基线 86–91%）。Agent：Qwen2.5 ALFWorld CR **128–133%**、RR≈**88%**（可超 Context）；GPT-OSS-120B ALFWorld CR **101–104%**、RR **94–95%**；但 GPT-OSS-20B τ²-Bench Structural CR 仅 **38.5%**、Synaptic **−92.3%**（成功率 62.0/56.3 vs Context 64.7）。抑制任务高 CR（97–100%）却 Neighbor RR 掉约 9–20 分。消融：FFN-only 优于连带改 attention；Structural 无 replay 也更抗遗忘；shared MoE 扩容抬 CR。
   - 局限：无独立 Limitations 节；Discussion 明确——冻结旧参≠冻结行为；Structural 折叠不减参数量，需剪枝/重组；巩固仍耗骨干前向算力；需可靠经验校验与用户信息保留/共享管控；跨任务 continual 与大 batch、超网络摊销成本列为 Future。失败条件：只报终答准确却不拆 CR/RR；或把「有上下文时能做」当已巩固；或在 τ² 类双控环境未测就宣称 Agent 经验可参数化。
   - 对办公 Agent 或 Agent 基础设施的意义：把「规程/偏好/工具文档灌进上下文」推进到可测的 **撤上下文后仍保留多少增益、伤多少旁路能力**。生产可对标：策略/连接器知识是外置检索还是可折叠 FFN 写入；序列更新后早期事实 CR 曲线；用户私有经验写入前的校验与共享边界。

3. **[XferAgent: Cross-Agent Experience Transfer for Self-Improving LLM Agents](https://arxiv.org/abs/2610.19581)**
   - 元信息：2026-10-14（abs：Submitted on 14 Oct 2026；cs.MA / cs.AI；McGill / Northwestern / Ohio / Mila；14 pages）；预印本；主题标签：Multi-Agent / 跨 Agent 经验迁移·local+shared 图 / Reconciliation·PPR 路由 / GAIA·ALFWorld·MBPP；分级：S
   - 核心问题：单 Agent 经验自改进已常见，但异构 Agent（不同框架/工具史）贡献的经验难对齐：盲目合并不可靠，整库共享又难挑对本任务有用的子集。如何在**保留本地细节**的同时做可路由的跨 Agent 经验迁移？
   - 机制/设计：**XferAgent**：(1) 每 Agent 本地经验图 \(\mathcal{G}_i^L\) + 共享图 \(\mathcal{G}^S\)；成功/失败分型节点，共享侧剥任务原文、终答与完整轨迹；(2) **Reconciliation**——同 id 合并，否则同型且 \(\cos\ge\theta_{\mathrm{rec}}\)；多候选时需相对次优至少 \(\delta_{\mathrm{rec}}\) 边距，否则新建，避免不可靠合并；(3) **Task-Conditioned Routing**——本地算任务相似锚点 → 共享侧 PPR + leave-one-agent-out 结果分 + 贡献者支持，扩成预算 \(B\) 的连通子图；(4) **Local–Shared Integration**——临时融合图再 PPR，融合结果分 \(s^{\mathrm{fused}}\) 混合本地统计与跨 Agent 先验，探索加成后选入 prompt；只对进 prompt 的经验回写 outcome。主评 GAIA（SmolAgents；跨框另含 OWL）+ ALFWorld + MBPP。
   - 证据：GAIA Test 301——GPT-5.6 Luna **52.16%**（No Memory 48.17；最强基线 ExpGraph 47.51；若干记忆法反低于无记忆）；Qwen3-Next-80B-A3B **29.57%**（AgentKB 28.90）。ALFWorld 274：**88.7%**（No Memory 84.7；AgentKB/ExpGraph 88.3）。MBPP 60：**53.3%**（No Memory/AgentKB 50.0）。三遍 GAIA val 165：累计准确 **56.36→67.88→74.55%**（独立 No Memory 52.12；含同题重复尝试）。跨框 2/4/8 Agent：宏均 **40.4→47.2→55.0%**。消融（Luna）：仅本地 **46.84** / 仅共享 **50.83** / 去掉 outcome 排序 **48.17** / 去掉连通约束 **46.84**（满配 52.16）。
   - 局限：正文 Limitations——剥离敏感字段但无形式化隐私保证；主聚焦文本经验；源/评任务分离不能排除语义重叠或预训练暴露。渐进实验与 Agent 数增长纠缠学习曝光量。失败条件：无边距地硬合并异构经验；或只做跨 Agent 相似检索却不看 leave-one-out 结果；或用「记忆法」却在强骨干上低于 No Memory 仍宣称有效迁移。
   - 对办公 Agent 或 Agent 基础设施的意义：给「多角色/多框架办公舰队」一条经验层协作合同——**共享可路由、本地可保留、合并需边距、选型看跨 Agent 成败统计**。生产可对标：异构连接器 Agent 间是否只传可共享摘要；路由预算 \(B\) 与连通约束；跨队复用须报告相对无记忆的净增益而非仅库规模。

1. **[Analyzing technical documents with Deep Review](https://research.google/blog/analyzing-technical-documents-with-deep-review/)**
