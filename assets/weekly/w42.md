## 一、论文（arxiv）

1. **[APDMem: Agent-Controlled Progressive Disclosure](https://arxiv.org/abs/2610.02472)**（预印本，10-01/05；JPMorgan）  
   \(L_0\)–\(L_3\) 多分辨率 + Controller 按需下钻；LongMemEval-S 87.8，平均只钻入 8% 会话。简单题不得默认读全文，verbatim 必须能落到 \(L_3\)。

2. **[DyadMem: How Agents Work with Users](https://arxiv.org/abs/2610.03020)**（预印本，10-02/05）  
   用户侧 + URAM 协作程序；Gold-Memory≈91 vs Full-Pipeline≈48–57（\(\Delta_{G2P}\) 巨大）；不安全删除率约 78–84%。验收须拆 Capture/Update/Recall，禁只刷终答。

3. **[Trained Agentic Context Management](https://arxiv.org/abs/2610.02404)**（预印本，10-01/05）  
   极简 harness：`read_chunk` + `spawn_subagent`；8K 预算下 RULER/OOLONG 逼近满窗 GPT。策略内学会切/并，而非只外挂压缩。

4. **[PRISMEM: Capability-Driven Self-Evolution](https://arxiv.org/abs/2610.06361)**（预印本，10-05；USTC+Microsoft）  
   五能力分榜演化再整合；BEAM-1M 63.39 vs 静态/演化基线约 +10–11 pp。记忆脚手架须按事实/时序/偏好/综合/拒答分门回归。

5. **[MemPilot: On-Demand Multimodal Memory Curation](https://arxiv.org/abs/2610.06830)**（预印本，10-05）  
   预建库 + 原始史双视图，运行时选 Retrieve/Curate 与模型档；Perf/Bal/Cost 前沿包住多基线。会议截图/附件按预算下钻，敏感史禁外委。

6. **[Attention Tax, Handoff Tax](https://arxiv.org/abs/2610.06069)**（预印本，10-05）  
   可测交叉深度 \(L^\ast\)：注意力税 > 交接税才拆多 Agent。账本对账深度 20/50/100 上分解显著优于单线程。选型先量退化曲线，再谈拓扑。

7. **[MINDSET: Energy-based Schema Evolution](https://arxiv.org/abs/2610.08586)**（预印本，10-06）  
   不可变 episode + 版本 schema（reinforce/supersede/split）；写库无 LLM 改写。偏好/计划变更：答题只吃有界原文包。

8. **[Beyond Corrected Memory: Execution Consistency](https://arxiv.org/abs/2610.08101)**（预印本，10-06）  
   CAVERT：N/V/U 证据充分判定 + 提交前闸；删证据后 82% 不可分合规/违规。记忆对 ≠ 职责可证（如审批撤销后仍下单）。

9. **[SquidAgent: Parallelize Wisely](https://arxiv.org/abs/2610.08647)**（预印本，10-06；NeurIPS 2026）  
   会话 fork + 约定块压再探索/对齐税；仅 \(\hat\rho>\alpha\) 才并行。吞吐约 ×2，质量不掉。能并就并是反模式。

10. **[Stale, Misattributed, or Late](https://arxiv.org/abs/2610.10265)**（预印本，10-07；Berkeley）  
    生成前失效：stale/misattribution/late；键控 supersession 在开域键失败时仍暴露过期值。终答 Acc 掩盖「脏 prompt」。

11. **[MAScope: Topology-Conditioned Diagnosis](https://arxiv.org/abs/2610.10126)**（预印本，10-07）  
    拓扑–失败强关联；真拓扑使 gpt-mini Macro-F1 +102%。值班先声明通信拓扑再读轨迹。

12. **[ReFold: Reversible Inter-Turn Context Folding](https://arxiv.org/abs/2610.07863)**（预印本，10-06；UCSB+Intel）  
    渲染层去重/折叠 + chunked 保前缀缓存 + `restore`；token −18%～−60%，resolve 不掉。无 restore 禁激进折叠。

13. **[What to Admit and How to Present](https://arxiv.org/abs/2610.11188)**（预印本，10-08）  
    准入（FC/PS）与呈现分治；ofj 失败 45%→20%，Gate 几乎不动。冲突记忆物理缺席，禁只改措辞。

14. **[REMORY: Residual Memory for Compaction](https://arxiv.org/abs/2610.11287)**（预印本，10-08）  
    可读摘要 + 有界 soft token；BrowseComp/Terminal 升、重复工具 −18%～−30%。摘要外缺口靠残差，精确记录仍走 archive。

15. **[Gated Memory: Admission-Controlled Formation](https://arxiv.org/abs/2610.11270)**（预印本，10-08；Samsung）  
    提取前话语级准入；「租了 SUV」不得固化为「拥有」。写入口污染下游检索救不回来；Multi-Hop 有代价须分表报。

16. **[Use and Disuse / Hippocam](https://arxiv.org/abs/2610.12124)**（预印本，10-08）  
    意图栈巩固 + 前缀递归压缩 + 消息树下钻；交错任务不掉点、冲突分辨领先。检查点须可 recall 到证据层。

17. **[Workerville: Organizational Behavior Account of Agent Safety](https://arxiv.org/abs/2610.11561)**（预印本，10-08）  
    主管×同伴×记忆先验；两负面常比三负面更险。企业多 Agent 须配置矩阵分表报泄密/高危写/假完成。

18. **[MemoType / CogMem / E-LEDGER](https://arxiv.org/abs/2610.11573)** / [11314](https://arxiv.org/abs/2610.11314) / [11552](https://arxiv.org/abs/2610.11552)（预印本，约 10-08/09）  
    情节·个人语义·一般语义分型；Claim vs Fact 防语义坍缩；代码策略闸 + 世界账本 + 隐规则沙箱验证。办公写库：分型检索 + 主观断言带源 + 工具成功≠态已知。

## 个人点评

1. **记忆研究完成「写入口 / 读准入 / 流水线分环」三层钉死。** Gated Memory 管形成前污染，Admit/Present 管进模前缺席，DyadMem/APDMem/PRISMEM 管 Capture·Update·Recall 与能力分榜；OffQuery 式「答对≠态干净」仍适用。企业记忆栈不能只买检索库。

2. **上下文压缩从摘要进化到「可逆渲染 + 残差软记忆 + 训练式分解」。** ReFold 保前缀缓存与 restore，REMORY 补摘要缺口，Trained ACM / Hippocam 把切并与意图巩固内化。办公长工单应回归：首步动作质量、重复工具率、cache 命中、不可恢复丢字。

3. **多 Agent 选型有了可测税与职责闸。** Attention/Handoff Tax 给交叉深度，SquidAgent 给层并行门槛，CAVERT/EMFA/MAScope/Workerville 分别钉执行一致性、决断步归因、拓扑诊断与组织前因。默认「越多 Agent 越好」继续降级。

4. **办公执行面本周明确「事件驱动 + 创建模拟 + 字节旁路」。** Cloudflare OS 把 Chat/Gmail 钩与 Docs·Slides 创建队列产品化；Workspace/Graph 附件票与转发草稿对齐人审车道；GenOffice 脱敏/知识库堵选区泄漏。生产先选车道（原生模拟写 / MCP 同步审 / 本机真文件），再选连接器。
