## 概述

这一周的主线是 **「办公执行层硬化 + 记忆作用域/评测变硬 + 审批权威下沉到会话与网关」**。论文侧密集出现写时多视图（AutoViewMem）、功能子图共进化（MACE）、知识工作 Pareto 评测（DolphinBench）、参数化跨会话记忆（RPMem）、非递归工具 I/O 压缩（CliffCompaction）、实体索引（EnSIMem）、技能作用域门闸（Scoped-ORC）、以及发信前草稿对齐基准（TWIST）；GitHub 则以 GenOffice 本地真文件引擎、AgentSafe 执行权威、Workspace MCP、OfficeAgent.NET / MAF HITL 护栏为主轴；大厂博客则用 OpenAI Workspace Agents 写闸、Microsoft Copilot Autopilot 独立身份、Elastic/MCP Tasks 可挂起审批、Zoho AgentInbox 独立邮箱，把「能改真文档」与「谁以何身份发副作用」写成产品契约。

## 一、论文（arxiv）

1. **[AutoViewMem: Self-Configuring Orthogonal Views for Conversational Long-Term Memory](https://arxiv.org/abs/2609.21940)**（预印本，约 09-21）  
   写时自适应多视图 + DPP 选低重叠投影，查询仍简单 top-K；离线按 Containment/Complementarity 巩固。LoCoMo/PersonaMem 全面优于 MemGAS/A-mem。办公落地：会议/邮件先按用户视图拆结构化卡再入库，权限挂 provenance。

2. **[MACE: Memory-Agent Co-Evolution with Adaptive Memory Graphs for Multi-Agent Systems](https://arxiv.org/abs/2609.21533)**（预印本，约 09-21）  
   MemGoG 功能子图 + 角色补丁投递 + 执行反馈共进化；八基准 Avg 81.11%，去 Coupler/MemGoG 掉点最大。把「调研→制表→审校」写成带 support/conflict/repair 的可复用手续。

3. **[DolphinBench: Mapping the Pareto Frontier of Agent Memory](https://arxiv.org/abs/2609.24971)**（预印本，09-22）  
   三人设知识工作 persona、600 道无提示动作题，强制报 accuracy/$/延迟；有/无金证双盲验证。Mem0 可冲准确率但非最省；排名随 harness 翻转。选型应看 Pareto，而非只盯回忆分。

4. **[RPMem: Learning Long-Term Recurrent Parametric Memory Across Sessions](https://arxiv.org/abs/2609.23466)**（预印本，09-22）  
   会话前向编译为定形潜变量 + 循环巩固门，解码到当前骨干 LoRA；换模型只重训解码器。PERMA/PersonaMem/PrefEval 显著优于全文与多项外存；查询历史 token=0。需另配可审计文本层。

5. **[Propose, Verify, Commit: Evidence-Grounded Memory for Long-Horizon Multi-Actor Conversations](https://arxiv.org/abs/2609.23465)**（预印本，09-22）  
   证据 append-only + 活跃态版本追溯；propose–verify–commit 写路径与两遍证据导航。GroupMem/EverMem 相对基线 +20pp 级。适合群聊/跨组决策修订的可审计记忆。

6. **[CliffCompaction: Cost-Efficient Compaction for Long-Horizon Coding Agents](https://arxiv.org/abs/2609.26779)**（预印本，09-23）  
   规则砍大工具 I/O、保任务指令与近窗；**整段丢弃旧 compaction，禁止摘要套摘要**。Terminal-Bench/SWE 上同预算优于原生摘要，且更省 KV。办公长工具链默认 compaction 配方。

7. **[EnSIMem: Entity-Structured Indexing for Long-Term Agent Memory](https://arxiv.org/abs/2609.27279)**（预印本，09-23）  
   主题 episode + `[entity][property]→episode` 索引，生成展开原文而非摘要；按需求覆盖自适应停检。LoCoMo 90%+、LongMemEval 92.8%。「索引寻址、原文作答」可直接映射邮件/纪要实体权限。

8. **[Scope Before You Persist: Preventing Cross-Family Interference in Agent Memory](https://arxiv.org/abs/2609.29144)**（预印本，09-24）  
   ORC 门闸认证技能后，Scoped 按族槽检索 vs Global 全库；同接受次数下 Global 6 次有害部署、Scoped 0。合同条款/报销规则/业务线话术必须「认证范围 = 检索范围」。

9. **[When Can Agents Forget Their Reasoning? ICLR for Long-Horizon Agent Context Compression](https://arxiv.org/abs/2609.29875)**（预印本，09-24）  
   只压刚完成步的低熵 reasoning，保动作/工具 I/O；外置态后可安全遗忘。WorkBuddyBench 均值升、token 降；Office 域需调参。可遗忘闸 = 「决议是否已写入纪要/表格」。

10. **[TWIST: A Proposed Benchmark for Intervention Quality in Conversational Memory](https://arxiv.org/abs/2609.28575)**（预印本，约 09-25）  
    测「何时该主动拦截草稿 vs 勿过度拦截」；Track B 硬负例配对。flat-RAG 召回高但误拦 16–43%。发信/回客户前对照 CRM·纪要的记忆层验收标准。

11. **[Agensh: Scaling Organizational Intelligence to 1,024 Agents](https://arxiv.org/abs/2609.26781)**（预印本，09-22）  
    无中心：共享 Git 工作区 + Mattermost + 类型化共享上下文（CLAIM/FAIL）；1→128 agents ProgramBench 均值约 +49%。多人并行起草/审订的去中心配方。

12. **[DocuTeam: Mixed-Initiative Multi-Agent Discussions around Evolving Documents](https://arxiv.org/abs/2609.29309)**（预印本，09-24）  
    文档块锚定 + Agent 主动开聊；N=20 盲评 Novelty/Specificity 显著升、steering −46%。多角色评审合同/方案应从聊天编排改成文档中介闭环。

## 个人点评

1. **记忆研究从「怎么检索」扩到「写在哪、何时忘、何时拦」。** AutoViewMem/EnSIMem 的写时结构、Scoped-ORC 的认证=检索范围、ICLR/Cliff 的可遗忘条件、TWIST 的漏拦/误拦配对，合在一起才是可上线的企业记忆栈。

2. **办公 Agent 的工具面本周形成「云读 + 本机写」双轨。** Workspace MCP / ask-marcel 管 Graph 只读与旁路大文件；GenOffice / OfficeAgent.NET / kordoc 管真 OOXML/公文档写回与防护帽。缺一轨都会在附件或发信上翻车。

3. **HITL 权威继续从产品开关下沉到会话与字节。** MAF 批准绑 AgentSession、openai-agents compaction/沙箱红线、AgentSafe MCP Guard、OpenAI Always ask + 域约束、Elastic 可挂起审批——共同主题是：审批观察值 = 将执行参数，且伪造历史/跨边界 grant/空鉴权必须 fail-closed。

4. **常驻 Agent 的身份问题被产品化。** Copilot Autopilot 的 agent user、Zoho AgentInbox 的独立邮箱、AgentSafe 的 compromised principal，都在说：借用员工 OAuth 长效令牌无法做归因与吊销；独立主体 + 赞助人/访问包才是租户默认。
