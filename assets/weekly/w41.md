# 周报 · w41

> 覆盖上一周：2026-09-28（一）— 2026-10-04（日）

## 概述

这一周的主线是 **「记忆写闸硬化 + 决策保持式压缩 + 副作用车道分轨」**。论文侧把共享记忆准入（CPB）、团队/个体有效性（HiCoMER）、稳定–可塑性诊断（MemProbe）、改写信用分配（MGPO）、分层可溯源程序（MemCodex）、组织 as-of 记忆（Mem++）、决策保持压缩（FOCUS）、持久注意力图（ReCAP）、主动 compact（AutoCompact）、以及「答对但共享态脏」（OffQuery / Global Coherence）钉成可验收合同；GitHub 则以 OpenShell 运行时闸、Hindsight 记忆、paperclip 工作面、GenOffice/kordoc 真文件护栏、Cloudflare OS Gatekeeper、Airlock 审批预览为主轴；大厂博客则用 OpenAI Dots（只读侦察 + Auto-review）、Anthropic×NVIDIA Vault/OpenShell、Microsoft Autopilot agent user、AWS Bedrock Managed Agents、Cloudflare OS 把「谁能写、写前谁批、批什么」写成产品契约。

## 一、论文（arxiv）

1. **[A Benchmark and Diagnostic Study of Epistemic Admission in Shared Agent Memory](https://arxiv.org/abs/2609.30813)**（预印本，约 09-25/28）  
   CPB：准入策略对候选输出 PROMOTE / REQUEST EVIDENCE / KEEP PRIVATE / ABSTAIN；Static 1200 情节 + Live 六 Agent 写回环。仅源类型治理门把 damage 压到 share-all 的约 0.11–0.15；Mem0 在 share-all 下 damage≈1.0。办公共享记忆必须拆「谁说的、是否独立」，禁用以库养库自引。

2. **[HasMem: Hard-Origin Adaptively Softened Memory for Long-Term LLM Agents](https://arxiv.org/abs/2609.30797)**（预印本，约 09-25/28）  
   Soft Bank 从冻结 token 嵌入起步，KEEP/SHRINK/EXPAND；全 KEEP 与硬 prompt 等价。MSC 重建 F1 升、EM 常降。可审计压缩路径：决议外置后才可 SHRINK。

3. **[Not All Memories Are Equal: Hierarchical Collaborative Memory (HiCoMER)](https://arxiv.org/abs/2609.30289)**（预印本，约 09-28）  
   Team 权威修订 Individual + 有效性感知重排；ORR@5 约 14–16 vs Flat RAG 45+。制度/会议决议 vs 个人工单笔记必须分层维护后再检索。

4. **[Probing Stability–Plasticity Tradeoffs (MemProbe)](https://arxiv.org/abs/2609.30558)**（预印本，约 09-28；EMNLP 2026）  
   Interference / Misinformation / Consolidation / Reconsolidation 探针出 SP 画像；同 Acc 可反维护策略（Graphiti vs LangMem previous-value 96 vs 68）。选型禁只盯终答 Acc。

5. **[Learning What to Remember: Long-horizon Counterfactual Memory Optimization (MGPO)](https://arxiv.org/abs/2609.37930)**（预印本，09-29）  
   改写边际剥离继承效用；SciREX 记忆均长 −78.7% 且簇/关系 F1 显著升。写闸应用「改写前后探针边际增益」训，而非终答或当前检索分。

6. **[FOCUS: Training-Free Decision-Preserving Context Compression](https://arxiv.org/abs/2609.37590)**（预印本，09-29；Microsoft M365 Research）  
   draft 引用频率估 span 未来依赖 + DefensiveVerify；OfficeBench Acc 升且 Peak/Dep −47%/−73%。compaction = 保决策因果 span，而非摘要过去。

7. **[Context Language Models](https://arxiv.org/abs/2609.37725)**（预印本，09-29；Meta 等）  
   上下文当可 Bash 编辑文件 + 多 Agent 并存 + Suffix Cache Reuse；BrowseComp-Plus 相对摘要 +11.4%、FLOPs −21.5%。可编辑上下文是新注入面，写闸仍须外置。

8. **[MemCodex: Self-Programming Hierarchical Memory](https://arxiv.org/abs/2609.39765)**（预印本，09-30）  
   skill/graph/summary/raw 分层程序可进化；默认路由回源回合。四基准 Acc 60.8、tok/q 约 3.4× 少于最强自适应基线。派生记忆必须可溯源。

9. **[Persistent Context Graphs (ReCAP)](https://arxiv.org/abs/2609.40118)**（预印本，09-30；UCSB+Microsoft）  
   注意力 EMA 图 + 保护集（用户指令/最新写）+ 依赖扩边；相对摘要压缩/冷恢复延迟约 −95%。骨架硬保护，可不额外调模型选上下文。

10. **[MemFit: Efficient Long-Term Agentic Memory](https://arxiv.org/abs/2610.00872)**（预印本，10-01）  
    原文 append-only + 段摘要只索引；相对 LLM-写记忆少 81–87% LLM 调用。摘要不得替换源回合。

11. **[Beyond Memory: Explicit Belief States (PoS)](https://arxiv.org/abs/2610.01415)**（预印本，10-01）  
    世界态+缺口+Sentinel+Trapping 恢复；ALFWorld 相对最强基线约 +23%。上下文管理从「留/压历史」推进到可审计当前世界态。

12. **[Global Coherence / Observation-Aliasing](https://arxiv.org/abs/2610.02036)**（预印本，10-01）  
    局部都对、团队仍错；共享预算须 commit 闸或 escrow。谁拥有不变量先于「更大模型」。

13. **[Mem++: Non-Destructive Memory for Organizational Agents](https://arxiv.org/abs/2610.02002)**（预印本，约 10-01/02）  
    整文档永存 + as-of 时序检索；OrgMemBench Overall 57.6 vs RAG 55 / A-Mem 44.5。政策/审批记忆：supersede 只改状态，审计可按日取证。

14. **[AutoCompact: Learning When to Compact](https://arxiv.org/abs/2610.02163)**（预印本，约 10-01/02）  
    主动 `compact()` + judge 纠偏 SFT→GRPO；SWE-bench 39.6 vs Base 30.4。when/what/how-continue 须进策略，不能只开长度 fallback。

15. **[Right Answers, Wrong States (OffQuery / ReGround)](https://arxiv.org/abs/2610.01244)**（预印本，约 10-01/02）  
    T3 高、T1/T2 崩；ReGround 先校验再共享。答对当前问 ≠ 共享知识库可复用。

## 个人点评

1. **记忆研究从「怎么检索」扩到「谁能写进共享库、何时可压、答对是否等于态干净」。** CPB/HiCoMER 的准入与分层、MemProbe 的 SP 画像、MGPO/MemCodex/MemFit/Mem++ 的写信用与溯源、OffQuery/Global Coherence 的共享态卫生，合在一起才是可上线的企业记忆栈。

2. **上下文压缩的验收口径变了。** FOCUS/ReCAP/AutoCompact/PoS 不再比「摘要多短」，而比决策是否保持、骨架是否保护、主动 compact 后动作是否自洽、信念缺口是否可恢复。办公长跑应把集合型任务与鉴权态救回列入 compaction 回归。

3. **副作用车道本周明确分轨。** Dots 只读侦察 vs Auto-review 写；OpenShell/BMA 工作负载外策略；Cloudflare 原生 Gatekeeper 模拟写 vs MCP 同步 `awaitDecision`；Airlock 操作员预览不回灌 Agent。生产先选车道，再选连接器。

4. **本机真文件层与云读层继续互补 hardening。** GenOffice 参数/监听/ZIP/IPC 护栏 + kordoc 布局/页界/空栏合同 + ask-marcel 只读爆破半径——缺一轨都会在附件或发信上翻车。
