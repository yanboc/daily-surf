## 概述

这一周的主线非常清晰：**前沿模型集体冲向「长程 agent + 网络安全能力」**，同时开源侧把「Agent Skill / Harness / 记忆」做成可安装、可复用的工程单元。论文上，多 agent 的记忆写读门控、skill 持续优化、以及对「换模型后记忆是否还活着」的实证，直接踩中后训练与 agent 基础设施兴趣点；GitHub 上 star 过千的几乎全是 skill 包与 harness，而不是新框架；大厂博客则一边发 Fable / Astra / Gemini 3.8 / Muse Spark，一边用形式化数学与「持久 Bot」产品原语证明 agent 已能扛长任务。

## 一、论文（arxiv）

1. **[Learning What to Retain: Gated-Memory Routing for Efficient Collaboration in Multi-Agent LLM Systems](https://arxiv.org/abs/2609.00237)**（预印本，2026-08-31）  
   多 agent 编排若只看 query 会失配中间态，若吃全量执行历史又成本爆炸。本文用 **Memory Write Gate + Retrieval Gate** 维护紧凑执行记忆，再据此做角色/骨干路由与自适应停机，把协作状态压缩成可决策的记忆面。

2. **[MASkills: Continual Skills Optimization for Multi-Agent LLM Systems](https://arxiv.org/abs/2609.02094)**（预印本，2026-09-02；EMNLP 2026 Findings）  
   相对难调用的经验记忆，**skill** 更可执行（何时做、怎么做、用什么工具）。MASkills 用 skill 条件信用分配 + 层级聚合 + 动量平滑，让 skill 库在精炼/归纳/合并/剪枝中持续进化（HotpotQA / LoCoMo / GAIA）。

3. **[Bilevel Coordinated Reflection: A Game-Theoretic Approach to Multi-Agent LLM Systems](https://arxiv.org/abs/2609.02750)**（预印本，2026-09-02）  
   把 orchestrator–worker 写成双层博弈，并分析 free-form reflection 在语义记忆空间上的随机游走；提出 **SRMA**：仅当环境接地评估风险下降才接受候选记忆。Kimi 系系统在 500 个 SWE-bench 实例上 72.2% vs 公开 mini-SWE-agent 70.8%。

4. **[Does Your Agent's Memory Survive a Model Upgrade? A Controlled Study of Memory Portability](https://arxiv.org/abs/2609.05339)**（预印本，2026-09-04）  
   换模型不等于记忆可迁移：同一历史在 LC-RAW / RAG / NOTES / 固定 schema KG 下表现不同；新模型可能「读不懂旧笔记」，embedding 混用会毁掉检索。对 agent harness / 记忆层选型是硬实证。

5. **[What Matters in On-Policy Distillation? A Perspective on Data Efficiency and Data Selection](https://arxiv.org/abs/2609.05198)**（预印本，2026-09-04）  
   面向推理后训练的 **On-Policy Distillation**：极端 1-shot OPD 仍有效，且更难样本常带来更大增益——直接服务「少数据、高质量后训练」偏好。

6. **[Trace2Tower: Transition-Aware EigenTrace Induction of Multi-Level Skills for LLM Agents](https://arxiv.org/abs/2609.05261)**（预印本，2026-09-04）  
   从原始轨迹抽象事件图，用对比谱分解抽出稳定、与成功对齐的多层次 skill，补上「扁平轨迹摘要」忽略的时序与结果条件拓扑。

## 个人点评

1. **记忆与 skill 正在从「提示词技巧」变成可学习策略。** Gated-Memory Routing / MASkills / SRMA / Trace2Tower 都在说同一件事：什么该写入、何时调用、如何用结果信号更新，比堆更大的上下文更重要。对陈彦博关注的 Agent Memory / Context Management，本周论文密度很高。

2. **开源热度集中在 Skill 与 Harness，而不是又一个编排 DSL。** archify、mattpocock/skills、ponytail、ECC、hermes-agent 说明社区赌的是「可移植的行为与工具包」；跟踪这些仓的接口约定，比追周更迭的 agent 框架更划算。

3. **大厂叙事统一成「长程 + 安全分级发布」。** Fable/Mythos、Astra Critical cyber、Gemini Flash Cyber、Muse 行为校准，都在用「同一模型、不同护栏与准入」卖 agent 能力。工程上更值得抠的是：cache 定价、tool-call 效率、不可逆动作确认——这些直接决定 harness 成本曲线。

4. **xAI 的 Bot 原语与 Meta 的 Second Brain 是产品侧镜像。** 一个解决「谁在持续负责」，一个解决「机构知识如何跨人沉淀」；合在一起就是个人 agent 记忆 × 组织知识层的完整拼图。
